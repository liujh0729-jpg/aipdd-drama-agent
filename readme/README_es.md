## ¿Qué es DramaClaw?

DramaClaw es una **línea de producción de código fuente abierto para drama con IA** — y, cada vez más, para cualquier historia visual que quieras contar con modelos generativos. Tiene dos caras que comparten una sola biblioteca de assets y un solo agente:

- **XiaHua — el lienzo infinito.** Un taller basado en nodos donde generas, editas y conectas libremente imágenes, vídeo, audio, sets 3D y guiones, y luego promueves lo que te gusta de vuelta a la serie. Aquí es donde hoy ocurre la mayor parte de nuestro trabajo creativo, y hacia donde va DramaClaw.
- **Series (XiaJi) — el pipeline.** Suelta un manuscrito o un guion y DramaClaw asume el trabajo pesado: estructurar la historia, planificar episodios, escribir guiones, dibujar storyboards y primeros fotogramas, sintetizar la voz en off, y montar la película final.

**Xia Director**, el agente integrado, opera en ambas: responde preguntas sobre tu proyecto, ejecuta tareas del pipeline, y puede construir y ejecutar grafos de nodos en el lienzo por ti.

Está hecho para creadores, estudios independientes e ingenieros creativos — ejecuta toda la «fábrica de drama» en tu propia máquina, sin unir una docena de herramientas desconectadas ni entregar tu material a un servicio cloud de caja negra. Aunque está construido alrededor del drama, el mismo lienzo y pipeline se extienden a anuncios cortos, vídeos de producto para e-commerce y otros formatos visuales.

- **Herramientas de vídeo** — texto / imagen / fotograma clave a vídeo, generación con referencia omnímoda con **referencias de archivo, enlace web y sobre-el-lienzo**, edición de vídeo, borrado, upscale, separación de audio, plantillas de cámara, análisis de plano; Seedance 2.5 está en el catálogo recomendado
- **Audio** — síntesis de voz con biblioteca de voces, voces de referencia, generación musical
- **Skills de lienzo** — skills de un clic como boceto-desde-contexto, fotograma-desde-contexto, set-de-fondo, scene-360, revisión de fotograma y planificación de grafo de beats
- **Pensado para lienzos grandes** — pestañas de lienzo, esquema de elementos, minimapa y marcadores de viewport, imán-alineación, renderizado LOD, selección múltiple y nodos de grupo, atajos de teclado, historial de revisiones con restauración, bloqueo por lienzo

<p align="center">
  <img src="../assets/pipeline.png" alt="DramaClaw pipeline — Ingest, Plan, Produce, Deliver" width="760"/>

Cada paso tiene su propia interfaz — ejecútalos en orden, salta pasos, retoma desde cualquier checkpoint, o incluso conecta tu propio orquestador.

- **Voz en off, composición de vídeo y exportación** — voz con conciencia emocional, ensamblaje de episodio, exportación de vídeo + subtítulos y el pack completo de assets
- **Visual Style** — sube una imagen de referencia para extraer parámetros de estilo y aplicarlos a todo el proyecto
- **Task Center** — estado, progreso, registros, cancelar / reintentar, retomar-desde-checkpoint para ejecuciones largas; los prerrequisitos se validan antes de encolar un trabajo

## ¿Por qué DramaClaw?

**Un lienzo que entiende de drama, y un agente que trabaja sobre él.** Los lienzos genéricos de nodos cablean cualquier cosa pero no saben nada de episodios, personajes o planos; las herramientas de serie conocen el oficio pero te encierran en un asistente. XiaHua te da el lienzo libre con nodos y skills conscientes del drama, y Xia Director se está construyendo para disponer, ejecutar y revisar esos grafos por ti. Esa combinación es hacia donde va DramaClaw.

**Hecho de la novela a la miniserie.** Las herramientas de flujo genéricas pueden cablear nodos, pero no saben qué es un «beat de episodio», no entienden por qué importa la coherencia de identidad de un personaje entre escenas, y no protegen el arco emocional de un capítulo a través de imagen + voz + edición. DramaClaw incorpora todo ese juicio en la herramienta.

**Lienzo y pipeline, no lienzo o pipeline.** La mayoría de las herramientas te dan o un lienzo de nodos libre o un asistente rígido. DramaClaw ejecuta ambos como dos vías paralelas sobre una sola biblioteca de assets: explora en el lienzo, compromete lo que funciona a la serie, proyecta la serie de vuelta sobre un lienzo. El agente trabaja en ambos.

**Cada paso es descomponible.** Cada etapa es una tarea asíncrona independiente con su propia interfaz. Ejecuta en secuencia, salta pasos, retoma a mitad — la cadena de herramientas es el producto en sí, sin caja negra oculta.

**Auto-hospedable, neutral en modelos.** Tu manuscrito, tus personajes, tus modelos, tus servidores. Usa modelos cerrados de frontera cuando quieras los mejores resultados; cambia a modelos open-weight cuando quieras control total. DramaClaw no te ata a ningún proveedor único.

## Requisitos del sistema

DramaClaw ejecuta toda la inferencia a través de una **pasarela compatible con OpenAI** — ya sea el servicio de pasarela oficial de DramaClaw o LocalNewAPI ([dramaclaw-gateway](https://github.com/dramaclaw/dramaclaw-gateway)) que enruta a los proveedores que configures. Nada ejecuta modelos en tu máquina, así que la huella local es ligera. Un portátil corriente o un VPS pequeño es suficiente.

| Elemento | Requisito |
|---|---|
| **CPU / RAM** | ≥ 2 vCPU / 4 GB recomendado (excluye la inferencia de modelos — esa corre en la pasarela) |
| **GPU** | No requerida para el pipeline estándar. Solo el extra `world` opcional (vóxel / panorama-a-3D) necesita una GPU + imagen CUDA |
| **Disco** | Unos pocos GB para las imágenes más los medios/estado generados bajo el volumen `ce-data` (sin mínimo estricto) |
| **SO** | macOS (Apple Silicon / Intel), Windows (Docker Desktop + backend WSL2), Linux (Docker Engine + plugin compose) |
| **Docker** | Docker + `docker compose` |
| **Puertos** | `8080` UI web · `8780` API REST · `3000` UI admin de LocalNewAPI (solo-host por defecto, ampliable) |
| **Almacenes de datos** | Ninguno requerido — sin Postgres, Redis, Celery ni Ray. Las tareas corren in-process; el estado vive en el sistema de archivos local (SQLite + archivos) |
| **Red** | Acceso de salida a la pasarela oficial `susciyuan.com`, y/o a los proveedores de modelos que configures en LocalNewAPI |

> El desarrollo local (sin Docker) además necesita Python 3.11–3.12 + [`uv`](https://docs.astral.sh/uv/) + `ffmpeg`. Prerrequisitos completos en la [guía de auto-hospedaje](../docs/en/guides/self-hosting.md).

## <a name="inicio-rápido"></a>Inicio rápido

### Docker (recomendado)

Cada Release de GitHub publica imágenes multi-arquitectura (amd64/arm64) en Docker Hub.

**Compilación desde fuente (por defecto)** — clona DramaClaw y LocalNewAPI ([dramaclaw-gateway](https://github.com/dramaclaw/dramaclaw-gateway)) en paralelo; `docker compose up -d --build` compila los tres servicios desde esos dos checkouts.

```bash
git clone https://github.com/liujh0729-jpg/aipdd-drama-agent.git
git clone https://github.com/dramaclaw/dramaclaw-gateway.git   # LocalNewAPI, compilado desde ../dramaclaw-gateway
cd dramaclaw

cp .env.example .env
# Edita .env — fija PROMPT_EXPORT_PASSWORD a un valor no predeterminado.

docker compose up -d --build   # compila y arranca tres servicios: api / newapi (LocalNewAPI) / web
```

Ambos checkouts son repos git normales: edita, `git pull`, recompila. ¿Solo cambió el código de DramaClaw? `docker compose up -d --build api web`. ¿Solo la pasarela? `docker compose up -d --build newapi`. ¿Clonaste la pasarela en otro sitio, o prefieres que Docker la obtenga de git? Fija `DRAMACLAW_GATEWAY_SRC` en `.env` a esa ruta o a `https://github.com/dramaclaw/dramaclaw-gateway.git#main`.

**Sin compilación** — extrae las imágenes publicadas (sin clonar la pasarela):

```bash
docker compose -f docker-compose.release.yml up -d
```

Abre la app en <http://localhost:8080>; la API REST está en <http://localhost:8780>. En **Settings → Model Config** elige una de:

- **Official** — pega tu clave DC (consíguela en <https://susciyuan.com>); sin mapeo de modelos. LocalNewAPI queda inactivo.
- **Custom** — un clic inicializa LocalNewAPI; luego añade tus propios canales upstream.
- **LocalNewAPI + Official Hybrid** — oficial para el pipeline principal, LocalNewAPI para canales extra.

Pasos completos en el [Inicio rápido](../docs/en/getting-started/quickstart.md).

Fija versiones o cambia de registro en `.env` (`DRAMACLAW_VERSION`, `DRAMACLAW_GATEWAY_VERSION`, `DRAMACLAW_IMAGE_PREFIX`) — esto aplica solo al modo de imagen (`docker-compose.release.yml`). China continental: fija `DRAMACLAW_IMAGE_PREFIX=claymore-registry.cn-chengdu.cr.aliyuncs.com/dramaclaw` y fija ambas versiones (el espejo ACR solo lleva tags fijados).

> ¿Migrando desde un checkout antiguo? Para la compilación desde fuente, primero `git clone https://github.com/dramaclaw/dramaclaw-gateway.git ../dramaclaw-gateway` (la pasarela ahora se compila desde ese checkout hermano; sin ella la compilación se detiene con `unable to prepare context`). `docker-compose.selfhosted.yml` / `docker-compose.selfhosted.release.yml` fueron eliminados — usa `docker-compose.yml` (compilación fuente) / `docker-compose.release.yml` (imágenes). Los nombres de servicio y los volúmenes `ce-data` / `newapi-data` no cambian; los datos existentes se reutilizan tal cual. El puerto de LocalNewAPI ahora solo se enlaza a `127.0.0.1` por defecto; fija `ST_NEWAPI_BIND=0.0.0.0` en `.env` si necesitas acceso remoto a él.

### Desarrollo local (uv + Python 3.11+)

```bash
git clone https://github.com/liujh0729-jpg/aipdd-drama-agent.git
cd dramaclaw

uv sync
cp .env.example .env && $EDITOR .env

uv run novelvideo api --port 8780   # arranca la API REST (CE por defecto en tareas inline, sin Ray/Redis)
```

Frontend en una segunda terminal: `cd frontend && pnpm install && pnpm dev`.

**Pasarela.** En modo **Official** no necesitas nada más. En modo **Custom** o **LocalNewAPI + Official Hybrid** la API espera una pasarela en `127.0.0.1:3000` cuyo archivo SQLite es `./state/newapi/one-api.db` (a eso escribe "Initialize" en Settings; `NEWAPI_ADMIN_BASE_URL` en `.env` ya apunta ahí). Ejecuta la imagen publicada con ese directorio montado:

```bash
mkdir -p state/newapi
docker run -d --name dramaclaw-gateway -p 127.0.0.1:3000:3000 \
  -v "$PWD/state/newapi:/data" \
  claymorelab/dramaclaw-gateway:v1.0.0-rc.24-dramaclaw.1
```

o ejecuta la pasarela desde fuente en el checkout hermano (`make dev-api` / `make dev-web` en [dramaclaw-gateway](https://github.com/dramaclaw/dramaclaw-gateway#develop), o `go build` y arranca el binario con `SQLITE_PATH=<path to>/dramaclaw/state/newapi/one-api.db`).

## Modelos y proveedores soportados

DramaClaw se mantiene neutral en modelos — todos los modelos de texto / imagen / vídeo / audio se conectan a través de una **pasarela compatible con OpenAI**. Elige el modo en **Settings → Model Config**:

- **Official (recomendado)** — pega tu clave DC (consíguela en <https://susciyuan.com>), guarda, listo. La pasarela oficial ya trae todos los mapeos de modelos que DramaClaw necesita; nada que configurar.
- **Custom** — un clic inicializa LocalNewAPI, luego añade tus propios canales de proveedor (claves API, IDs de modelo) en su UI de admin. Cada modelo que DramaClaw llama pasa por tus canales.
- **LocalNewAPI + Official Hybrid** — mantén los modelos oficiales para el pipeline principal y añade canales extra (por ejemplo un flujo de vídeo ComfyUI local) a través de LocalNewAPI.

Recorrido completo en [Configurar modelos](../docs/en/getting-started/configuring-models.md).

### LocalNewAPI: dramaclaw-gateway

El servicio `newapi` de `docker-compose.yml` es [**dramaclaw-gateway**](https://github.com/dramaclaw/dramaclaw-gateway), el fork propio de DramaClaw de [New API](https://github.com/QuantumNous/new-api). Habla el contrato **DC-Media** que DramaClaw usa para imagen / vídeo / audio (roles de medio, referencias, primeros / últimos fotogramas) y convierte cada solicitud a la API nativa del proveedor. Imagen: [`claymorelab/dramaclaw-gateway`](https://hub.docker.com/r/claymorelab/dramaclaw-gateway) en Docker Hub, fijada por `DRAMACLAW_GATEWAY_VERSION` en `.env`. Queda inactiva en modo Official y solo se usa una vez cambias a **Custom** o **LocalNewAPI + Official Hybrid**.

Adaptadores de proveedor incluidos hoy en la pasarela (mira la [matriz de soporte de canales](https://github.com/dramaclaw/dramaclaw-gateway/blob/main/docs/providers/en/README.md) para el estado de verificación): ComfyUI · MiniMax H3 / Hailuo · VolcEngine Doubao / Seedance · Alibaba · Kling · Jimeng · Vertex AI · Gemini · OpenAI / Sora · Suno. ¿Quieres otro proveedor? La pasarela tiene un [generador de andamiaje y guía de contribución](https://github.com/dramaclaw/dramaclaw-gateway/blob/main/CONTRIBUTING.md).

| Etapa             | Modo Official                              | Modo Custom / Hybrid (LocalNewAPI)                    |
|----------------------|----------------------------------------------------|-----------------------------------------------------------|
| **Texto / LLM**  | modelos `DC-*-LLM`, sin mapeo                    | cualquier canal chat compatible con OpenAI               |
| **Imagen**       | gpt-image · nano-banana                            | cualquier canal de imagen registrado en la pasarela      |
| **Vídeo**        | Seedance serie 1.0 / 1.5 / 2.0 · happyhorse       | cualquier adaptador de vídeo DC-Media (Seedance, Hailuo, Kling, ComfyUI, …) |
| **Voz en off**   | IndexTTS2                                          | cualquier canal de audio registrado en la pasarela       |
| **Grafo narrativo** | Cognee (`DC-cognee-embedding`)                     | cualquier canal de embedding                              |
| **Runtime de tareas** | inline in-process (sin Ray / Redis / Celery)       | igual                                                     |
| **Almacenamiento** | sistema de archivos local                          | igual                                                     |

## <a name="in-development"></a>En desarrollo

Estos se están construyendo en abierto y aún no están en un release. Observa las ramas, o ven a ayudar.

- **Xia Director sobre el lienzo** — el agente crea y conecta nodos, actualiza datos de nodos, dispone y agrupa nodos, ejecuta acciones y construye grafos de flujo completos, con cada comando del lienzo aprobado primero en el navegador abierto.
- **Catálogo de flujos y skills comunitarias** — un catálogo de 11 skills de flujo y 60 recetas (drama, anuncios e-commerce, ads de personaje IP, campañas sociales, estilos animé / Pixar / LEGO / kung-fu…) que disponen grafos de generación completos; skills y recetas como bundles instalables, exportables y compartibles
- **agent-kit** — un paquete portable que lleva los mismos flujos de DramaClaw a Hermes, OpenClaw, WorkBuddy, Claude Code y Codex
- **Escenario Previz** — un escenario de blocking 3D en el navegador como nodo del lienzo: línea de tiempo multi-pista, rigs y trayectorias de personajes, modelo de cámara de lente / sensor reales, seguimiento de primer plano, y luego captura el plano encuadrado directo al siguiente nodo. Rama: `feat/previz-canvas-node`
- **Historias interactivas** — puntos de ramificación sobre el lienzo, compilados a una historia ink y exportados como un reproductor HTML autónomo, con estadísticas de playtest y cobertura de rutas. Rama: `feat/canvas-fmv`
- **Anuncios interactivos** — las skills y recetas de anuncios de arriba, combinadas con reproducción ramificada, para vídeos de producto que el espectador puede dirigir
