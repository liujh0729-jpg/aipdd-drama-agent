## ما هو AIPDD-Agent-Claw؟

<div dir="rtl">

DramaClaw هو **خط إنتاج مفتوح المصدر للدراما بالذكاء الاصطناعي** — وبالتدريج، لأي قصة بصرية تريد روايتها بالنماذج التوليدية. له وجهان يتقاسمان مكتبة أصول واحدة ووكيلاً ذكياً واحداً:

- **XiaHua — اللوحة اللانهائية.** طاولة عمل قائمة على العقد، تولّد وتحرّر وتربط الصور والفيديو والصوت والمجسمات ثلاثية الأبعاد والسيناريوهات بحرية، ثم ترقّي ما يعجبك إلى المسلسل. هنا يحدث معظم عملنا الإبداعي اليوم، وإلى هنا يتّجه DramaClaw.
- **المسلسل (XiaJi) — خط الإنتاج.** ألْقِ بمخطوطة أو سيناريو ليتولّى DramaClaw الشاقّ: هيكلة القصة، وتخطيط الحلقات، وكتابة السيناريوهات، ورسم لوحات القصّة وإطاراتها الأولى، وتوليف التعليق الصوتي، ومونتاج الفيلم النهائي.

**Director**، الوكيل الذكي المدمج، يطلّ على الوجهين معاً: يجيب عن أسئلتك حول مشروعك، ويحرّك مهام خط الإنتاج، ويمكنه أن يبني ويشغّل مخططات العقد على اللوحة نيابةً عنك.

صُمّم للمبدعين والاستوديوهات المستقلة ومهندسي الإبداع — شغّل «مصنع الدراما» كاملاً على جهازك، دون أن تُفتّل أدواتٍ منفصلة لا رابط بينها أو تسلّم موادّك لخدمة سحابية صندوقٍ أسود معتِم. ورغم أنه مبنيّ حول الدراما، فإن اللوحة وخط الإنتاج نفسهما ينقلان إلى الإعلانات القصيرة ومقاطع المنتجات التجارية والصيغ البصرية الأخرى.

</div>

## <a name="what-we-added"></a>ما يضيفه تفرّع AIPDD

بدأنا من لوحة DramaClaw اللانهائية وأعدنا بناء كامل المكدّس حولها. فوق **بناء من المصدر مكتفٍ ذاتيًا برخص متعددة** (لا صور خارجية، لا نداءات صادرة افتراضيًا) يُضيف التفرّع القدرات التي تجعله **مصنع دراما يعمل بالوكيل**:

**١ · وكيل مدمج — Director.** يقرأ مشروعك ويتفقّد التقدّم ويدفع مهام النص / اللقطة ويدقّق اكتمال المخرجات ويشغّل أعمال المسار ويرتّب ويشغّل عُقد اللوحة نيابةً عنك — كل أمر على اللوحة يُراجع أولًا في المتصفح.

**٢ · خادم MCP كامل — نحو ١٠٠ أداة.** جسر stdio واحد (`uv run`) يفتح النظام بأكمله أمام **Claude Code وCodex** وأي عميل MCP — أدوات `aipdd_drama_*` + `vectcut_*`، وCE-owner عبر loopback أو مفتاح API بصيغة `st-`. [دليل ←](../docs/en/guides/mcp-claude-code.md) ويتفرّع إلى:

- **أدفعة بنقرة واحدة (صفحة الأدوات)** — استنساخ الفيديو، مزج الفيديو القصير، أنيميشن السبورة، فيديو الشرح المتحرك، فكرة-إلى-فيديو (سطر واحد → فيلم جاهز)، استنساخ الصوت وتركيبه، مزامنة الشفاه، استبدال الشخص، استبدال المنتج، إزالة علامة الماء من الفيديو، إزالتها من الصورة، دبلجة الفيديو، واستخراج نص دوينين.
- **أفعال التوليد على اللوحة** — *صورة*: توليد / تعديل / إعادة رسم / توسيع الأطراف / إعادة إضاءة / تكبير / زوايا متعددة / تعديل بقالب / استخراج الموجّه · *فيديو*: نص-إلى-فيديو / صورة-إلى-فيديو / مرجع شامل / تكبير / تعديل / تمديد · *صوت*: فصل الغناء عن المصاحبة / موسيقى · *نص*: توليد / ترجمة / نص قصصي / استخراج نص من فيديو / كتابة تسويقية.
- **أتمتة وتنسيق بنقرة واحدة** — قائد تلقائي لمرحل storyboard (أسلوب → سيناريو → حلقات → لوحات → إطار أول)، وتوليد دفعي لفيديوهات اللقطات / الرسوم / موجّهات الفيديو حسب مدى الإيقاعات، ومنسّق `run_pipeline` بأوضاع `manual` / `checkpoint` / `auto` مع حالة التشغيل / إلغاء / اقتراح الإعداد.
- **تحرير مسودة Jianying / CapCut** — يجمع اللوحات والتعليق الصوتي والترجمات في مسودة مونتاج حقيقية عبر خدمة VectCut (١٣ أداة `vectcut_*`).

**٣ · هندسة ثقيلة للاستضافة الذاتية.** بوابة DramaClaw (AGPL-3.0) وDA-2 (Apache-2.0) وml-sharp (Apple) **مضمّنة (vendored)** تحت [`third_party/`](../third_party/README.md)؛ يُبنى المكدّس بالكامل من المصدر، ونداءات الكتالوج / موجز الإصدارات البعيدة أصبحت الآن **باختيارك (opt-in)** بدل التشغيل الافتراضي.

باختصار: **AIPDD-Agent-Claw = لوحة DramaClaw + وكيل + سطح MCP بنحو ١٠٠ أداة + بناء مكتفٍ ذاتيًا** — نظام يمكنك قيادته يدويًا أو بالموجّهات أو من وكيل ذكاء اصطناعي آخر.

## القدرات الأساسية

### XiaHua — اللوحة اللانهائية

<p align="center">
  <img src="../assets/xiahua-canvas.jpg" width="900" alt="لوحة XiaHua: سير عمل لفيلم قصير من 17 عقدة رسمه وشغّله Director من مطالبة واحدة"/>
</p>
<p align="center"><sub dir="rtl">مطالبة واحدة إلى Director (يمين) تحوّلت إلى هذا السير من 17 عقدة و32 رابطاً على اللوحة (يسار): الموجز ← اتجاه القصة ← مراجع الشخصيات والديكور ← خمس إطارات لقطات ← خمس فيديوهات لقطات ← تعليق صوتي وموسيقى تصويرية ← المونتاج النهائي.</sub></p>

<div dir="rtl">

- **18 نوعاً من العقد على لوحة واحدة** — رفع، توليد/تحرير الصور، توليد لوحة القصّة، السيناريو، سياق النبضة، الفيديو، تركيب الفيديو، قصة الفيديو، الصوت، النمط، المهارة، المجموعة، تعليق نصي، عارض بانوراما 360°، العالم ثلاثي الأبعاد، التصدير وغيرها. اربطها بحرية؛ كل عقدة تحتفظ بسجل توليدها الخاص.
- **أدوات الصور** — توليد، تحرير، إعادة رسم، توسيع خارج الإطار، إعادة إضاءة، ترقية دقة، تعدد زوايا، تحرير بالقالب، استخراج المطالبة العكسية، كشف العلامات؛ **جدار أنماط من 45 شكلاً بصرياً للدراما القصيرة** لتحويل الصورة إلى صورة.
- **أدوات الفيديو** — تحويل النص/الصورة/الإطار المفتاحي إلى فيديو، توليد بالمرجع الشامل مع **مرجع ملفات وروابط ويب وعناصر على اللوحة**، تحرير الفيديو، المسح، ترقية الدقة، فصل الصوت، قوالب الكاميرا، تحليل اللقطة؛ Seedance 2.5 في الكتالوص الموصى به.
- **الصوت** — توليف كلامي بمكتبة أصوات وأصوات مرجعية، وتوليد موسيقى.
- **مهارات اللوحة** — مهارات بنقرة واحدة مثل الرسم من السياق، والإطار من السياق، وخلفية الديكور، والمشهد 360°، ومراجعة الإطار، وتخطيط نبضات القصة.
- **مبني للوحات الضخمة** — تبويبات اللوحة، ومخطط العناصر، والخريطة المصغّرة وإشارات التصفّح، والمحاذاة اللاصقة، والتصيير متدرّج التفاصيل، والتحديد المتعدد وعقد المجموعات، واختصارات لوحة المفاتيح، وسجل المراجعات مع الاستعادة، وقفل لكل لوحة.
- **الإيداع في المسلسل** — معاينة الأثر، ثم ترقية عقدة واحدة أو دفعة كاملة إلى مكتبة الأصول أو إلى حلقة؛ وإسقاط المسلسل مجدداً على لوحة من الإعدادات المحفوظة.
- **Director World — ديكور متّسق مكانياً** — صورة ← ديكور ثلاثي الأبعاد بتقنية Gaussian Splat ولوحات بانوراما 360° كعقد على اللوحة: ديكور افتراضي قابل للتأطير يثبّت البنية المكانية وحركة الشخصيات ومواضع الكاميرا، فيبقى الموقع ذاته متسقاً عبر اللقطات; أطّر اللقطة في العارض ثلاثي الأبعاد، والتقطها، واستخدمها خلفيةً للتوليد التالي.

### المسلسل (XiaJi) — خط الإنتاج

<p align="center">
  <img src="../assets/pipeline.png" alt="خط إنتاج DramaClaw — استيعاب، تخطيط، إنتاج، تسليم" width="760"/>

<div dir="rtl">

لكل خطوة واجهتها الخاصة — شغّلها بالترتيب، أو تخطَّ خطوات، أو استأنف من أي نقطة تحكّم، أو حتى صِل منصّة تنسيق خاصة بك.

- **استيعاب مُهيكل** — المشاريع الجديدة تبني الحلقات والشخصيات والمشاهد مباشرة من المخطوطة أو السيناريو (مع دعم Fountain)، دون حاجة إلى رسم معرفي أو تضمين؛ يبقى مسار رسم القصة Cognee للمشاريع القديمة.
- **مكتبة الأصول واتّساق الهوية** — الشخصيات والمشاهد والأدوات الصوتية والصوتيات منظمة حسب الغرض والمجلد؛ هويات ثابتة عبر الحلقات، وصور شخصيات، ونسخ مغايرة لكل حلقة.
- **تخطيط الحلقات وتوليد السيناريو** — تجزئة الفصول، وتخطيط النبضات، وأقواس متعدّدة الحلقات؛ أوضاع سيناريو تكيّفي/حرفي/مَرحَلي مع حلقات مراجعة وإصلاح.
- **لوحات القصّة والإطارات الأولى** — توليد مُوجَّه بالنبضة ومنمّط، وتقسيم الشبكة، واختيار من مجمّع الصور.
- **التعليق الصوتي وتوليف الفيديو والتصدير** — كلام مدرك للم المشاعر، وتجميع الحلقات، وتصدير الفيديو والترجمات، وحزمة الأصول كاملة.
- **النمط البصري** — ارفع صورة مرجعية لاستخراج معلمات النمط وتطبيقها على المشروع بأكمله.
- **مركز المهام** — الحالة، والتقدّم، والسجلات، والإلغاء/إعادة المحاولة، والاستئناف من نقطة التحكّم في التشغيلات الطويلة؛ تُتحقّق المتطلبات قبل إدراج المهمة في الطابور.

## لماذا AIPDD-Agent-Claw؟

<div dir="rtl">

**لوحة تفهم الدراما، ووكيل يعمل عليها.** اللوحات العقدية العامة تصل أي شيء بأي شيء لكنها لا تعرف شيئاً عن الحلقات أو الشخصيات أو اللقطات؛ وأدوات المسلسلات تعرف الصنعة لكنها تحبسك في معالج خطوة بخطوة. يمنحك XiaHua اللوحة الحرة بعقد ومهارات واعية بالدراما، ويُبنى Director ليصمّم تلك المخططات ويشغّلها ويراجعها نيابةً عنك. هذا المزيج هو وجه DramaClaw.

**مبني للتحويل من رواية إلى مسلسل قصير.** أدوات سير العمل العامة يمكنها وصل العقد، لكنها لا تعرف ما هي «نبضة الحلقة»، ولا تفهم لماذا يهمّ اتّساق هوية الشخصية عبر المشاهد، ولا تحرس القوس العاطفي للفصل عبر الصورة + الصوت + المونتاج. يبني DramaClaw كل هذا الحكم داخل الأداة.

**الوحة وخط إنتاج، لا هذه أو تلك.** تمنحك معظم الأدوات إما لوحة عقد حرّة أو معالجاً جامداً. يشغّل DramaClaw الاثنين كمسارين متوازيين فوق مكتبة أصول واحدة: استكشف على اللوحة، وأودِع ما ينجح في المسلسل، وأعد إسقاط المسلسل على لوحة. ويعمل الوكيل على الاثنين.

**كل خطوة قابلة للتفكيك.** كل مرحلة مهمة غير متزامنة مستقلة بواجهتها الخاصة. شغّلها تباعاً، أو تخطَّ خطوات، أو استأنف في المنتصف — سلسلة الأدوات نفسها هي المنتج، دون صندوق أسود خفيّ.

**قابل للاستضافة الذاتية، ومحايد تجاه النماذج.** مخطوطتك، شخصياتك، نماذجك، خوادمك. استخدم نماذج المصادر المغلقة المتقدمة حين تريد أفضل النتائج؛ وتحوّل إلى النماذج مفتوحة الأوزان حين تريد تحكّماً كاملاً. لن يحبسك DramaClaw ضمن مورّد واحد.

</div>

<div dir="rtl">

|---|---|
| **المعالج / الذاكرة** | ≥ 2 نواة / 4 جيجابايت مُوصى (لا يشمل استدلال النماذج — يعمل على البوابة) |

| **نظام التشغيل** | macOS (Apple Silicon / Intel)، وWindows (Docker Desktop + خلفية WSL2)، وLinux (Docker Engine + إضافة compose) |
| **Docker** | Docker + `docker compose` |
| **المنافذ** | `8080` واجهة ويب · `8780` واجهة REST API · `3000` واجهة إدارة LocalAPI (على المضيف فقط افتراضياً، يمكن توسيعها) |

## <a name="quick-start"></a>البدء السريع

<div dir="rtl">

### نقرة واحدة (macOS / Windows) — مستحسن إن أردت تشغيله فحسب

لا حاجة لأوامر الطرفية. احصل على الشيفرة (استنساخ أو **تنزيل ZIP** ثم فكّه)، ثم انقر نقرًا مزدوجًا فوق مشغّلين في جذر المستودع **بالترتيب**:

| | macOS | Windows |
|---|---|---|
| **١ · تثبيت** | نقر مزدوج على `安装环境-Setup.command` | نقر مزدوج على `安装环境-Setup.bat` |
| **٢ · تشغيل** | نقر مزدوج على `启动系统-Start.command` | نقر مزدوج على `启动系统-Start.bat` |

- **مشغّل التثبيت يثبّت كل شيء**: أدوات Xcode للسطر الأوامر ← Homebrew ← Colima (آلة Docker) ← Docker CLI + compose على macOS، أو WSL2 ← Docker Desktop على Windows؛ ثم يولّد `.env` من `.env.example` ويبني صور `api` / `web` / البوابة لأول مرة من المصدر (البوابة مضمّنة تحت `third_party/dramaclaw-gateway` فلا يُسحب شيء من مستودع صور). **مشغّل التشغيل** يرفع المكدّس وينتظر حتى يستجيب الموقع فعلًا ثم يفتح متصفحك على <http://localhost:8080>.
- **كل خطوة idempotent** — إذا فشل شيء، أصلح السبب وانقر مجددًا لتُكمل. عند النجاح تُغلق النافذة ذاتها؛ وعند الفشل تبقى مفتوحة لتقرأها.
- **أول تشغيل على macOS**: قد يحجب Gatekeeper ملف `.command` غير موقّع — انقر بزر الماوس الأيمن على الملف → **فتح** (أو اسمح به في إعدادات النظام → الخصوصية والأمان).
- **Windows**: **لا** تشغّله «كمسؤول» — Docker Desktop يُثبَّت لكل مستخدم ونافذة بصلاحية مرتفعة ستضعه حيث لا يجده المشغّل. (إعداد WSL يطلب موافقة نظام لمرة واحدة — وهذا متوقع.)
- **إعادة البناء بعد تعديل الشيفرة**: `bash 启动系统-Start.command --rebuild` (macOS) / `启动系统-Start.bat --rebuild` (Windows). النقر المزدوج الافتراضي لا يعيد البناء فيبقى سريعًا.

> هذا المسار يستخدم `docker-compose.aipdd.yml`: `api` و`web` والبوابة كلها تُبنى من المصدر (البوابة من النسخة المضمّنة `third_party/dramaclaw-gateway`)، مع SQLite ومهام داخل العملية، بلا Postgres/Redis/Celery و**بلا سحب أي صورة خارجية**. قد يستغرق أول بناء 40–90 دقيقة على اتصال بطيء (عمليات التشغيل اللاحقة بالثواني). للدخول وربط النماذج راجع [أول تشغيل](#first-run).

### Docker (مُوصى به)

كل إصدار على GitHub ينشر صوراً متعددة المعمارية (amd64/arm64) إلى Docker Hub.

</div>

**البناء من المصدر (افتراضي)** — استنسخ DramaClaw وLocalAPI ([dramaclaw-gateway](https://github.com/dramaclaw/dramaclaw-gateway)) جنباً إلى جنب؛ يبني `docker compose up -d --build` الخدمات الثلاث من عمليتَي الاستنساخ هاتين.

```bash
git clone https://github.com/liujh0729-jpg/aipdd-drama-agent.git
git clone https://github.com/dramaclaw/dramaclaw-gateway.git   # LocalAPI, built from ../dramaclaw-gateway
cd dramaclaw

cp .env.example .env
# Edit .env — set PROMPT_EXPORT_PASSWORD to a non-default value.

docker compose up -d --build   # builds and starts three services: api / newapi (LocalAPI) / web
```

<div dir="rtl">

كلا الاستنساخين مستودعا git عاديان: عدّل، و`git pull`، وأعد البناء. تغيّر كود DramaClaw فقط؟ `docker compose up -d --build api web`. البوابة فقط؟ `docker compose up -d --build newapi`. استنسخ البوابة في مكان آخر، أو تفضّل أن يجلبها Docker من git؟ اضبط `DRAMACLAW_GATEWAY_SRC` في `.env` على ذلك المسار أو على `https://github.com/dramaclaw/dramaclaw-gateway.git#main`.

**دون بناء** — اسحب الصور المنشورة بدلًا من ذلك (لا حاجة لاستنساخ البوابة):

</div>

```bash
docker compose -f docker-compose.release.yml up -d
```

<div dir="rtl">

افتح التطبيق على <http://localhost:8080>؛ واجهة REST API على <http://localhost:8780>. في **الإعدادات ← ضبط النماذج** اختر أحد:

- **رسمي** — الصق مفتاح DC الخاص بك (احصل عليه من <https://susciyuan.com>)؛ لا حاجة لخرائط نماذج. تبقى LocalAPI خاملة.
- **مخصّص** — نقرة واحدة تهيّئ LocalAPI؛ ثم أضف قنواتك المصدرية الخاصة.
- **مزيج LocalAPI + الرسمي** — الرسمي للخط الرئيسي، وLocalAPI للقنوات الإضافية.

الخطوات الكاملة في [البدء السريع](../docs/en/getting-started/quickstart.md).

ثبّت الإصدارات أو بدّل السجل في `.env` (‏`DRAMACLAW_VERSION`، و`DRAMACLAW_GATEWAY_VERSION`، و`DRAMACLAW_IMAGE_PREFIX`) — هذه تنطبق على وضع الصور (‏`docker-compose.release.yml`) فقط. للشرق الأوسط/الصين القارية: اضبط `DRAMACLAW_IMAGE_PREFIX=claymore-registry.cn-chengdu.cr.aliyuncs.com/dramaclaw` وثبّت الإصدارين (يعكس مرآة ACR الوسوم المثبّتة فقط).

</div>

> تنتقل من استنساخ أقدم؟ للبناء من المصدر، أولاً `git clone https://github.com/dramaclaw/dramaclaw-gateway.git ../dramaclaw-gateway` (تُبنى البوابة الآن من عملية الاستنساخ الشقيقة هذه؛ وبدونها يتوقّف البناء برسالة `unable to prepare context`). حُذِف `docker-compose.selfhosted.yml` / `docker-compose.selfhosted.release.yml` — استخدم `docker-compose.yml` (بناء من المصدر) / `docker-compose.release.yml` (صور). أسماء الخدمات ومجلّدا `ce-data` / `newapi-data` دون تغيّر؛ تُعاد استخدام البيانات القائمة كما هي. منفذ LocalAPI يربط الآن بـ `127.0.0.1` فقط افتراضياً؛ اضبط `ST_NEWAPI_BIND=0.0.0.0` في `.env` إن احتجت وصولاً بعيداً إليه.

<div dir="rtl">

### استضافة سحابية / VPS (Linux) — نشر مشترك أو عام

على خادم Linux (VPS خاص بك أو نسخة سحابية)، شغّل نفس مكدّس البناء من المصدر مع Docker Engine وإضافة `docker compose` — ثبّتهما عبر مدير الحزم في توزيعتك أو وثائق Docker الرسمية لنظام Linux، ثم:

```bash
# 1 · get the code and configure it
git clone https://github.com/liujh0729-jpg/aipdd-drama-agent.git
cd aipdd-drama-agent
cp .env.example .env
#    Edit .env: set ST_LOCAL_PASSWORD, PROMPT_EXPORT_PASSWORD and your model
#    keys / official DC key before you start.

# 2 · build & bring the stack up (api / newapi gateway / web, all from source)
docker compose -f docker-compose.aipdd.yml up -d --build
```

- **المنافذ.** `8080` واجهة الويب · `8780` واجهة REST API · `3000` إدارة LocalAPI (مرتبط بـ `127.0.0.1` افتراضيًا). ضع **وكيلًا عكسيًا مع TLS** (Caddy / Nginx / Traefik) أمام `8080` وأبقِ `8780` / `3000` داخليين؛ افتح `80` / `443` فقط في الجدار الناري / مجموعة الأمان.
- **أول البناء يحتاج متّسعًا** — خصّص للمضيف ≥ 8 GB ذاكرة و≥ 40 GB قرصًا، وإلا قُتل بناء الواجهة الأمامية بنفاد الذاكرة.
- **الدخول** بحساب الآلة الواحدة `local` باستخدام `ST_LOCAL_PASSWORD` (أو كلمة المرور لمرة واحدة المطبوعة في `docker compose -f docker-compose.aipdd.yml logs api` عند أول تشغيل).
- **متعدد المستخدمين؟** نسخة المجتمع مصمّمة لمالك واحد. لخدمة عدة مستخدمين فعّل `ST_CE_MULTI_USER` وضع مصادقة حقيقية + HTTPS في المقدّمة. ملاحظات الإنتاج الكاملة: [دليل الاستضافة الذاتية](../docs/en/guides/self-hosting.md).

</div>

```bash

docker run -d --name dramaclaw-gateway -p 127.0.0.1:3000:3000 \
  -v "$PWD/state/newapi:/data" \
  claymorelab/dramaclaw-gateway:v1.0.0-rc.24-dramaclaw.1
```

<div dir="rtl">

أو شغّل البوابة من المصدر في الاستنساخ الشقيق (‏`make dev-api` / `make dev-web` في [dramaclaw-gateway](https://github.com/dramaclaw/dramaclaw-gateway#develop)، أو `go build` وشغّل الثنائي مع `SQLITE_PATH=<path to>/dramaclaw/state/newapi/one-api.db`).

</div>

## <a name="first-run"></a>أول تشغيل وكيفية الاستخدام

أيًا كان مسار التثبيت الذي اخترته، يقلع التطبيق بنفس الطريقة:

1. **افتح الواجهة** على <http://localhost:8080> (مشغّلات النقرة الواحدة تفتحها لك). واجهة REST API على <http://localhost:8780>؛ المتصفح يخاطب `web` فقط، وهو يوجّه عكسيًا إلى `api`.
2. **سجّل الدخول.** إعداد `docker-compose.aipdd.yml` يفعّل دخول الآلة الواحدة (الحساب `local`).
   - إذا ضبطت `ST_LOCAL_PASSWORD` في `.env` فسجّل الدخول بالحساب `local` وتلك كلمة المرور.
   - إذا تركتها فارغة فالخادم **لا** ينشئ حسابًا نيابةً عنك: أول شاشة هي **نموذج التهيئة**، اضبط فيها اسم المستخدم وكلمة المرور الأولية. أول حساب يكون مديرًا أعلى ويُغلق النموذج نهائيًا؛ تُضاف الحسابات لاحقًا من **الإعدادات → إدارة المستخدمين**.
3. **اربط نماذجك** — اذهب إلى **الإعدادات ← إعداد النموذج** واختر وضعًا (التفاصيل في [النماذج والموردون المدعومون](#supported-models)):
   - **رسمي** — الصق مفتاح DC من <https://susciyuan.com>؛ كل النماذج معيّنة مسبقًا ويبقى LocalAPI خاملًا.
   - **مخصّص** — نقرة واحدة تهيّئ LocalAPI ثم أضف قنواتك العلوية الخاصة (مفاتيح API ومعرّفات النماذج) في واجهة إدارته.
   - **Hybrid LocalAPI + الرسمي** — الرسمي للمسار الرئيسي وLocalAPI لقنوات إضافية.
4. **ابدأ الإبداع** — بابهان إلى مكتبة الأصول نفسها:
   - **مسار المسلسل**: أدخل مخطوطة أو سيناريو (Fountain مدعوم) ودع AIPDD-Agent-Claw يخطّط الحلقات ويكتب النصوص ويرسم اللوحات والإطارات الأولى ويركّب التعليق الصوتي ويقصّ الفيلم النهائي. كل مرحلة مهمة مستقلة في **مركز المهام** — شغّلها بالترتيب أو تخطّاها أو استأنف من أي نقطة تحكّم.
   - **اللوحة**: افتح اللوحة اللانهائية وألقِ / اربط عُقدًا (صورة، فيديو، صوت، نص، مشهد ثلاثي الأبعاد…) للاستكشاف بحرية، ثم ارفع ما يعجبك إلى مسلسل.

ابقَ محدّثًا: انقر مجددًا فوق مشغّل **التشغيل** لإعادة الإقلاع؛ تحقّق من المكدّس العامل بـ `docker-compose -f docker-compose.aipdd.yml ps` وتابع السجلّات بـ `... logs -f api`. للجولة الكاملة راجع [دليل المنتج](https://neo-flying.feishu.cn/docx/JGNTdsjJuo748TxJkxecoYs2nth) و[البدء السريع](../docs/en/getting-started/quickstart.md).

## <a name="supported-models"></a>النماذج والمورّدون المدعومون

<div dir="rtl">

يبقى DramaClaw محايداً تجاه النماذج — كل نماذج النص/الصورة/الفيديو/الصوت تتصل عبر **بوابة متوافقة مع OpenAI**. اختر الوضع في **الإعدادات ← ضبط النماذج**:

- **رسمي (مُوصى به)** — الصق مفتاح DC (احصل عليه من <https://susciyuan.com>)، واحفظ، وانتهى. تشحن البوابة الرسمية مسبقاً كل خرائط النماذج التي يحتاجها DramaClaw؛ لا شيء للضبط.
- **مخصّص** — نقرة واحدة تهيّئ LocalAPI، ثم أضف قنوات مورّديك الخاصة (مفاتيح API، معرّفات نماذج) في واجهة إدارتها. كل نموذج يستدعيه DramaClaw يمرّ عبر قنواتك.
- **مزيج LocalAPI + الرسمي** — احتفظ بالنماذج الرسمية للخط الرئيسي وأضف قنوات إضافية (مثل سير عمل فيديو ComfyUI محلي) عبر LocalAPI.

> 🧠 **اختر مصدر الحوسبة بنفسك — تكلفة أقل وتحكم أكبر.** صُمّمت البوابة لتختار *أنت* أين تعمل كل عملية توليد:
> - **طاقة AIPDD الخاملة (خفض التكلفة).** ربط قناة **AIPDD** يسمح للتوليد بالعمل على **مجموعة الحوسبة الخاملة** في المنصّة، فتُنفَّذ مهام المسلسلات الثقيلة بدُفعات بجزء يسير من التسعير عند الطلب — أكبر رافعة لخفض تكلفة الإنتاج. سجّل في <https://www.aipdd.work> للحصول على مفتاح AIPDD API، ثم أضِفَه كقناة في **Settings → Models & Channels**.
> - **NewAPI، ادمج بحرية.** تتيح لك بوابة **NewAPI** المدمجة تسجيل مزوّدين عديدين كقنوات و**دمجها كما تشاء** — الرسمي، AIPDD، خادم تستضيفه بنفسك، أو أي نقطة نهاية متوافقة مع OpenAI — لكل نموذج ولكل مرحلة. لقنوات NewAPI نوصي **بالبحث عن مزوّديك بنفسك ومقارنة الأسعار**؛ قائمة مرجعية منتقاة هنا: <https://aiworkin.feishu.cn/wiki/F2WUwonOjikoDHkg1ERcDuPqnjf>.
> - **ComfyUI على معالج رسوماتك — أرخص طريقة لتشغيل التوليد على اللوحة.** موجِّه **ComfyUI** من الدرجة الأولى يحوّل توليد الصور/الفيديو إلى سير عمل يعمل على **أجهزتك**: معالجك يقوم بالتصيير **دون استهلاك حصة سحابية لكل استدعاء** — الأعمال الثقيلة لا تكلّفك سوى الكهرباء، أقل بكثير من أي نموذج مُستضاف. سجّل نقطة نهاية ComfyUI المحلية كقناة في وضع **Custom** أو **Hybrid**.
>   - **أسهل طريقة لتثبيت ComfyUI** — بلا تثبيت يدوي ولا بيئة Python: نزّل **عميل الحوسبة (算力客户端)** المضمّن لدينا ثم شغّل المثبّت: <https://aiworkin.feishu.cn/wiki/ShOuwFDdBimuqCkz2Oqcofwdnm7>.
>
>   <img src="../assets/Weixin%20Image_20261010102709_97_221.png" width="520" alt="عميل الحوسبة من AIPDD — ثبّت ComfyUI وشغّل مهام اللوحة على GPU محلي"/>

الشرح الكامل في [ضبط النماذج](../docs/en/getting-started/configuring-models.md).

</div>

### LocalAPI: dramaclaw-gateway

<div dir="rtl">

خدمة `newapi` في `docker-compose.yml` هي [**dramaclaw-gateway**](https://github.com/dramaclaw/dramaclaw-gateway)، تفرّع DramaClaw الخاص من [New API](https://github.com/QuantumNous/new-api). تتحدّث تعاقد **DC-Media** الذي يستخدمه DramaClaw للصور/الفيديو/الصوت (أدوار الوسائط، المراجع، الإطار الأول/الأخير) وتحوّل كل طلب إلى واجهة المورّد الأصلية. الصورة: [`claymorelab/dramaclaw-gateway`](https://hub.docker.com/r/claymorelab/dramaclaw-gateway) على Docker Hub، مثبّتة بـ `DRAMACLAW_GATEWAY_VERSION` في `.env`. تبقى خاملة في الوضع الرسمي ولا تُستخدم إلا حين تتحوّل إلى **المخصّص** أو **مزيج LocalAPI + الرسمي**.

</div>

<div dir="rtl">

محوّلات المورّدين الجاهزة في البوابة اليوم (راجع [مصفوفة دعم القنوات](https://github.com/dramaclaw/dramaclaw-gateway/blob/main/docs/providers/en/README.md) للتحقق من الحالة): ComfyUI · MiniMax H3 / Hailuo · VolcEngine Doubao / Seedance · Alibaba · Kling · Jimeng · Vertex AI · Gemini · OpenAI / Sora · Suno. تريد مورّداً آخر؟ للبوابة [مولّد هياكل ودليل مساهمة](https://github.com/dramaclaw/dramaclaw-gateway/blob/main/CONTRIBUTING.md).

</div>

| المرحلة | الوضع الرسمي | الوضع المخصّص/المختلط (LocalAPI) |
|---|---|---|
| **النص / LLM** | نماذج `DC-*-LLM`، بلا خرائط مطلوبة | أي قناة دردشة متوافقة مع OpenAI |
| **الصور** | gpt-image · nano-banana | أي قناة صور مسجّلة في البوابة |
| **الفيديو** | سلسلة Seedance 1.0 / 1.5 / 2.0 · happyhorse | أي محوّل فيديو DC-Media (Seedance، Hailuo، Kling، ComfyUI، …) |
| **التعليق الصوتي** | IndexTTS2 | أي قناة صوت مسجّلة في البوابة |
| **رسم القصة** | Cognee (‏`DC-cognee-embedding`) | أي قناة تضمين |
| **زمن المهام** | داخل العملية (لا Ray / Redis / Celery) | نفسه |
| **التخزين** | نظام ملفات محلي | نفسه |

## <a name="in-development"></a>قيد التطوير

<div dir="rtl">

تُبنى هذه علناً ولم تدخل إصداراً بعد. راقب الفروع، أو تعال وساعِد.

- **Director على اللوحة** — ينشئ الوكيل العقد ويربطها، ويحدّث بيانات العقد، ويرتّب العقد ويجمعها، ويشغّل إجراءات العقد، ويبني مخططات سير عمل كاملة، مع اعتماد كل أمر على اللوحة أولاً في المتصفح المفتوح.
- **كتالوص سير العمل ومهارات المجتمع** — كتالوص من 11 مهارة سير عمل و60 وصفة (دراما قصيرة، إعلانات تجارية، إعلانات شخصيات IP، حملات اجتماعية، أنمي/Pixar/LEGO/كونغ فو…) ترتّب مخططات توليد كاملة؛ مهارات ووصفّات كحزم قابلة للتثبيت والتصدير والمشاركة.
- **agent-kit** — حزمة محمولة تجلب سير عمل DramaClaw نفسه إلى Hermes وOpenClaw وWorkBuddy وClaude Code وCodex.
- **مسرح المعاينة البصرية** — مسرح سدّ ثلاثي الأبعاد داخل المتصفح كعقدة على اللوحة: خط زمني متعدد المسارات، وتجهيزات شخصيات ومسارات، ونموذج كاميرا بعدسة/مستشعر حقيقي، وتتبع اللقطة القريبة، ثم التقط اللقطة المؤطّرة مباشرة إلى العقدة التالية. الفرع: `feat/previz-canvas-node`.
- **القصص التفاعلية** — نقاط قرار متفرّعة على اللوحة، تُصرَّف إلى قصة ink وتُصدَّر كلاعب HTML مكتفٍ ذاتاً، مع إحصاءات الاختبار وتغطية المسارات. الفرع: `feat/canvas-fmv`.
- **الإعلانات التفاعلية** — مهارات ووصفات الإعلانات أعلاه، مع تشغيل متفرّع، لمقاطع منتجات يمكن للمشاهدين توجيهها.

</div>
